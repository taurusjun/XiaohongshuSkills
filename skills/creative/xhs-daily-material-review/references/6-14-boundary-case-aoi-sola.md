# 苍井空类素材：身份敏感但有普世价值的边界案例

## 问题

苍井空是前AV女优。按内容策略，**写真偶像/グラビア/セクシー女優跳过**。但苍井空≠普通写真女优——她已转型为艺人/实业家多年，她的新闻往往不是性感内容，而是社会议题或人情故事。

## 边界判断指标

一条素材是否要走**特殊通道**（入库但谨慎发布），而非直接跳过，满足以下条件：

| 条件 | 示例 |
|------|------|
| 核心内容不是性感/身体展示 | 入境中国被识破→讨论性行业女性出入境困境 |
| 去掉身份后仍有普世传播价值 | 「行业禁止横向联系，我们做了24年唯一朋友」=跨越规则的友谊 |
| 内容涉及社会议题/行业规则披露 | 出入境法对性工作者的不平等对待 |
| 引语和场景非擦边性质 | 24年前合照+重逢回忆，无任何性描写 |

## 判定规则

- 如果素材属于**「社会议题/行业规则/人情故事」**且**不涉及性感描写** → 可写，但标题不能利用「前AV女优」作为擦边钩子
- 如果素材涉及**身体描写/性感穿搭/写真集/擦边标题** → 直接跳过
- 如果素材涉及**医疗/健康类**身体话题（如乳腺胸）→ 跳过，纯擦边
- 发布前需评估：这条会不会把小红书推荐算法带偏？

## 小红书算法风险

即使内容质量高，苍井空身份可能导致推荐算法往写真/性感方向偏移。建议：
- 优先走公众号（公众号读者对身份不太敏感，看内容质量）
- 如果要在小红书发，标题和封面不能暗示原身份
- 观察第一条的数据后再决定是否继续发同类

## 6/14案例

「禁止横向联系的唯一朋友」— 讲的是AV行业内部禁止女优之间私下交往，苍井空和早坂瞳偷偷做了24年朋友的故事。内容有普世价值（行业规则之下的友情），无擦边内容。但最终因为身份敏感+非主赛道，没写。
