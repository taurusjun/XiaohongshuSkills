# 6/2 迭代案例：岚24年底片 & ALLY

## 案例1：岚24年前底片 (id=1978)

素材类型：Instagram帖子+粉丝评论（公开社交素材）
预估天花板：8.5-8.7
实际迭代轨迹：7.8 → 7.0 → 7.3 → 7.2 → 8.0 → 8.7 → 8.2

### 关键迭代节点

| 轮次 | 分数 | 改了什么 | 结果 |
|------|------|---------|------|
| v1 | 7.8 (建议发布) | 初始版：摄影师翻底片+松本润点赞 | 评语：情感细腻但缺少爆发力 |
| v2 | 7.0 (暂缓) | 加了五人站位细节、松本润时空对位、结尾呼应 | 更严的reviewer接了，指出情绪太圆满、人物太干净、爆点被温柔分解 |
| v3 | 7.3 | 缩写标题、删掉"某种意义上"抒情段、补二宫棱角 | 改标题有效，但棱角中途滑回感动基调 |
| v4 | 7.2 | 二宫段落展开、结尾加呼应 | 边际效应出现 |
| v5 | 7.2→8.0 | 新reviewer接 | 不同reviewer评分偏差可达0.8分 |
| v6 | 8.0→8.7 | 松本润点赞段扩写、加2002-2026时间锚点 | 爆点扩写有效 |
| v7 | 8.7→8.2 | 精简点赞段、加"回到日常"反转解读 | 改过了——更简洁反而削弱 |

### 核心教训

1. **素材天花板不可破**：Instagram帖+粉丝评论的组合，最高只到8.7。因为读者永远是"旁观第三手信息"
2. **爆点扩写的边际收益**：松本润点赞从2段扩到5段，分数+0.7分；再精简到3段，-0.5分。爆点段落在文章中占15-20%篇幅是最优密度
3. **标题改"终了"→"结束"** 去掉翻译腔，+0.3分
4. **reviewer切换导致分数波动±0.8分**：不是某一版的写法问题，是delegate_task采样不同model的结果。8分以上波动0.5分以内可接受
5. **6轮后放弃**：第6轮后每次改动带来的增量从+0.5降至+0.2再到负数。3轮+上限规则成立

## 案例2：ALLY从白领到偶像 (id=1971)

素材类型：杂志采访稿（周刊Playboy 6/2）
预估天花板：7.8-8.0
实际迭代轨迹：6.7 → 7.3 → 8.0 → 7.7 → 6.5 → 8.0

### 核心教训

1. **二次过滤媒体素材不可冲9分**：所有信息都经过记者编辑加工，缺乏原始语气的直接引语
2. **脆弱点虚构有害无益**：加"面试前关灯""辞职那天拎纸箱"等合理推演场景反而被扣分（0→8.0→6.5）
3. **标题"发币"冲突点有效但非决定性**：标题从"真相不是你想的那样"→"团靠发币成立"，+0.3分
4. **素材备选检查更重要**：如果先查DB发现这篇是采访稿而不是第一手素材，可能一开始就换素材了

### 素材天花板判定特征（当出现以下特征时立即放弃）

| 特征 | Reviewer原话 | 出现轮次 | 行动 |
|------|-------------|---------|------|
| "所有信息都是公开采访的重新组织" | 第4轮 | 换素材 |
| "文章缺少第一人称的对话或内心独白" | 第3轮起始终存在 | 写作无法解决 |
| "搜索到的所有她说过的话都是通过媒体转述的" | 第4轮 | 素材本质问题 |
