# Session 6/8 迭代教训

## 1. 单事件采访/节目素材属于短news，不是长文story

本session处理的素材类型（篠田麻里子40岁采访、武元唯衣毕业节目、小坂菜绪综艺企划、一之濑美空初C博客）全部是「单事件素材」——由一次采访/一期节目/一篇博客产出的内容。

之前review时用了长文story的标准（8+分为合格），但这类素材的信息量本质上是「单次事件」，不存在多素材合并的深度。reviewer给5.8-7分的区间是这类素材的合理天花板。

**处理方式**（6/8修正）：
- 单事件采访/节目素材 = **短news**（即使rewritten_content写了1000+字，也还是短news）
- 短news review合格线 = **7分**，不是8分
- 不用追8+，7分就可以告知用户

**判断方法**：
- 素材来源 = 一次节目/一篇采访/一次博客更新 → 短news
- 素材来源 = 多篇同主题素材合并 → 才有可能是长文story
- 一之濑美空的博客原文1629字，写出来1106字 → 仍然是单事件短news

## 2. review的爆发点评分在单事件素材中系统性偏低

单事件素材的信息密度固定（原文就这么多），reviewer要求的「具象场景/数字/对话」在这类素材中天然不足。这不代表文章写得差——而是素材类型的天然天花板。

6/8 session的数据说明：
- 一之濑美空原文1629字 → reviewer要求「被通知Center那刻在现场的物理场景细节」
- 但原文只说了「乃木坂工事中内で発表がありました」，没有更多细节
- 这不是写作问题，是素材本身没有提供

**对策**：review时对单事件素材的信息量做「素材上限判断」，不过度要求不存在的场景细节。

## 4. 爆发点布局：倒叙 vs 大后期爆发

6/8 session 的小坂菜绪文章经历了"倒叙→平铺→大后期爆发"的结构迭代。

**关键发现**：
- **倒叙（把核心句放开头）** → review扣分：核心悬念提前剧透，后续1000字沦为背景补充，阅读驱动力下降
- **大后期爆发（先铺垫背景/场景/配角，最后扔核心句）** → review加分：悬念持续，读者会带着"前面说的这些到底指向什么"的疑问一路读下去

**判断方法**：
素材的核心爆点是一个"引语/表态/决定"类的（小坂说"我不同意"、美空说"责任重到说不出话"），而非包含时间线反转的悬疑类——这类素材用大后期爆发优于倒叙。
- 倒叙适用场景：时间线长的反转故事（"先告诉你结局，再解释怎么走到这里的"）
- 大后期适用场景：一句话/一个态度就是全部爆点的（"慢慢铺垫，最后才说"）

## 5. "美貌→难相处"标题框架的有效性验证

6/8 session标题改造路径：
原标题「小坂菜绪想退出难相处6名单」→ 用户反馈"不够吸引人" → 尝试多个包含"美貌"的标题 → 最终「太美被说难相处，后辈连话都不敢说」被用户认可（xhs_len=16）

**效果判断**：
- 把素材所属人物的先赋属性（美貌/身材/年龄/出身）直接放进标题，制造"属性本该带来好处→但实际上带来问题"的反差
- 这种标题对路人吸引力强，因为预设了"到底有多XX才会这样？"的好奇
- 限制条件：素材中必须真实包含了"因美貌被贴标签"的内容，不能硬造

## 6. 五期生证言作为"标签制造隔阂"的逻辑锚点

小坂菜绪文中引入5期生下田和松尾樱的证言（"我们想和小西前辈更亲近，但因为她是气难6成员……反而不知道该怎么开口"），有效完成了从"有人被贴标签"到"标签本身在制造问题"的逻辑推进。

**可复用的叙事模板**：
当文章核心矛盾是"标签/人设与真实的冲突"时，找一个"第三方受标签影响者"的证言作为逻辑锚点，比作者直接下结论更有说服力。这个定理在日向坂、樱坂、乃木坂的群像类素材中均可复用。
