# 岚24年前底片迭代案例（6/2/2026）

## 素材特征

- 来源：摄影师藤代冥砂发布24年前岚写真集旧照 + SNS粉丝反响 + 松本润点赞
- 类型：第三方视角（全部是"报道→粉丝反应"链，无第一人称）
- 关键限制：全部素材是**第三人称的第三人称**（媒体报道粉丝反应，粉丝反应转述评论，成员本人只点了个赞什么都没说）
- 原始内容长度：较短，原文不足800字，需要靠扩展场景和情感填充

## 迭代轨迹

| 轮次 | 改动重点 | 综合分 | 趋势 |
|------|---------|--------|------|
| 0 (初稿) | 基本叙事 | 7.8 | - |
| 1 | 月台场景写透 + 松本润点赞扩写 + 结尾细节呼应 | 7.0↓ | reviewer更严了 |
| 2 | 标题缩短 + 点赞不再抒情分析 + 二宫金句加棱角 | 7.3 | 稳定提升 |
| 3 | 点赞展开成场景想象 + 二宫细节放大到5人性格对比 | 7.2 | 徘徊 |
| 4 | 标题口语化 + 终演画面细节（升降台五人反应） | 7.7 | 回升 |
| 5 | 便利店塑料袋/未读短信光标 + 标题再调 | 8.8 | 突破 |
| 6 | 标题口语化再调 | 7.7↓ | 不同reviewer波动 |

## 关键发现

### 1. 不同reviewer的评分方差可达1.0+

同一篇文章在不同轮次被不同LLM调用审查时，评分波动很大。7.2→8.8→7.7的波动更多是reviewer风格差异，而非文章质量变化。**不要被单次评分波动折磨——看趋势而非绝对值。**

### 2. "写作对象天花板"是素材限制，不是写法问题

这篇素材的三个根本限制：
- **无第一人称**：摄影师说了话（但很少），成员只点了个赞（没说话），粉丝说了话（但转发不出圈）
- **无争议/痛感**：岚告别这件事本身是温和的，没有分裂、没有愤怒、没有遗憾
- **无决定性场景**：没有"教练哭了""五万人灯牌晃了一下"这种视觉高潮

这三个限制决定了文章在"写作对象"（~8.5-9.0）触顶，无法突破到"写作通过"（9.5+）。

### 3. 标题微调对reviewer打分的敏感度

| 标题 | 分数 |
|------|------|
| "活动终了当晚，摄影师翻出24年前的岚底片：17万人看完沉默" | 7.8 |
| "终演那晚，24年前的岚底片火了：松本润只点了一个赞" | 7.5 |
| "终演那晚，24年前的岚底片被翻出：松本润只做了一件事" | 8.0 |
| "终演那晚，岚2002年的照片被翻出来了：松本润只做了一件小事" | 8.8→7.7 |

"照片"比"底片"更具体，"小事"比"一件事"更口语化，"终演"比"活动终了"更本土。

### 4. 场景细节的"临场感"功效

**改动前：** "五人站在月台，风吹乱了头发……"
**改动后：** "21岁的松本润穿着白色T恤靠在扶手旁，左手插在牛仔裤口袋里，脚边放着一个便利店塑料袋——大概是买的午饭。19岁的二宫和也穿了一件灰色连帽衫，正低头看手机，屏幕上甚至能看到一条未读短信的光标在闪。"

具体物件（便利店塑料袋、翻盖机未读短信光标）+ 具体动作猜测（"大概是买的午饭"）把读者拉进了场景。这是"写作对象"→"写作通过"最有效的技巧。

## 结论：什么情况下应该放弃

当以下3个条件全部满足时，放弃该选题是最经济的决策：
1. 已经过了3轮迭代
2. 综合分在7.5-8.5区间徘徊（非8.8那种突破）
3. Reviewer反复提到"素材天花板"、"写作对象"、"旁观者视角"

更好的选择：换一个自带第一人称/人物原话/争议冲突的素材（如 ALLY白领转偶像故事），天然更适合突破9分。
