# 6/21 写稿Review改稿循环经验

## 路由错误：我向往的蓝天3周年（长文story写成短news）

- 素材2,842 chars，完整演唱会报道（开场→新曲披露→队长发言→安可→2026年末live发表）
- 因为没加载skill，跳过stage 1b content_ja阅读，只看title_score低（1.6）就错误判断为「粉丝向短讯」
- 只写了328字，密度10.4%，退回重写
- **教训**：content_ja ≥ 2,000 chars + 有事件时间线 = 长文story，不管title_score多低都要读content_ja

## Renwei拒绝的典型问题：FRUITS ZIPPER

原稿被renwei拒绝（exit 1），10处命中/2类聚集：
- **短句轰炸（4处）**：连续短句「好难！」「看起来好难…」「这什么啊…」「从来没有见过的动作！」→ 合并为叙述句
- **破折号聚集（6处）**：结尾升华「因为她们知道——只有在最艰难的挑战面前仍然保持笑容的人，才能被称为真正的偶像」→ 替换为休息室真实场景（瘫倒大笑+截图+Jumbo吐槽）
- **修复模式**：砍掉升华句/万能展望/意义拔高，替换为具象场景细节

## 定向改稿技巧：从素材中提取未被使用的信息点

佐藤健NG发布会（7.7→8.0+）：
- 原文只聚焦了佐藤健的「眼神像猎物」
- 素材中还有未使用的：赏金回答魔幻场景（寿司/肉→房貸→驾照）、二宫拍合影的猎人构图、ウエンツ的「こんな記者会見あってたまるか！」
- 补了2个场景后信息增量+内容深度都提升
