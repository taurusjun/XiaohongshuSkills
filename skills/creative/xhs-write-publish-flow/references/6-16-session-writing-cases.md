# 6/16 写作模式与案例记录

## 逝世纪念类逆袭长文（中村玉緒案例）

素材特征：86岁逝世+完整人生弧线（梨园之女→嫁巨星→14亿债务→经理人赌注→综艺女王）

### 写作方法
1. **开篇用去世新闻切入，但不煽情** — 直接陈述事实（6月9日因肺炎去世，3天后公布），然后立刻过渡到她传奇的人生弧线
2. **核心意象贯穿全文** — 「击穿心脏」是经理人的原话请求，作为标题和全文锚点反复出现。岛田绅助打给秋刀鱼的电话是第二锚点
3. **采访原话作为骨架** — 不只用第二手叙事，经理人吉田正和的采访原话（「击穿心脏」「心臓、撃ち抜いてええんですね？」）作为情绪顶点
4. **结尾克制** — 「14亿债务换来的笑声」作为总结，最后一句「这不是天赋，不是运气。这是胆量。」收束但不升华
5. **标题去人名化** — 「她拜托人『击穿我的心脏』」去掉中村玉绪名字后仍然有钩子。副标题「14亿债务逼出的日本综艺女王」补充具体信息

### 同类素材检测信号
- 逝世纪念+有完整人生弧线的报道
- 包含「采访原话+具体数字+戏剧性反转」三要素
- 经理人/亲友的访谈比本人陈述更有说服力

## 男偶像双人采访→女性向内容转化（目黑蓮×高橋文哉案例）

素材特征：杂志《CLASSY.》长篇双人采访（5729字），核心hook是师徒传承

### 写作方法
1. **去除杂志粉圈向内容** — 删除「1问1答」类轻量问答（喜欢的食物/穿搭等），只保留有故事弧线的核心对话
2. **核心钩子定位** — 「我配合你」这句话是两人的情感连接点，Snow Man粉丝认识「配合」在Jr.时代的特殊含义，普通读者也能感受到承诺的重量
3. **结构**：开场hook（雨中的握手）→ 高桥从零练动作 → 拍戏中的信任细节 → 目黑说「我觉得像」
4. **去男团感** — 不强调颜值/人气，突出「老手认出了当年的自己」这种普世情感

### 适用场景
- 双人采访含「师徒/前后辈/传承」关系
- 有具体的引语（至少1条三要素齐备）作为情感顶点
- 杂志类采访必须筛选：1问1答和日常穿搭类可以直接跳过

## 分析评论类续篇（野呂佳代案例）

素材特征：已有逆袭旧稿（握手会2人→戛纳），新素材是行业趋势分析（~1050字评论）

### 写作方法
1. **判断方式**：新素材是「行业评论」而非「新事件」，不适合独立长文 → 写一篇分析评论类的续篇短news（~700字）
2. **引用旧稿的关键节点**（2人握手会、精修照片等）作为读者已知背景，不重复展开
3. **核心观点**：时代从「遙不可及的明星」转向「身边气味的人」→ 野吕佳代站在时代正中央
4. **结构**：旧事简述→行业分析观点→剧组评价（女性版大泉洋）→结论
5. **字数判定**：~700字合理，因为素材本身就是评论性内容，不需要补场景细节

## pipeline模式确认（6/16）

对于纯粉丝向晒照（小栗有以温泉照、小嶋阳菜西西里）：
- 设 `publish_mode: caption` + `preselected: 1`
- 不动 rewritten_title 和 rewritten_content
- pipeline 的 caption 模式会直接以图片+标题发布，不需要文字稿
