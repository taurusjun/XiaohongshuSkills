# 6/27 关联素材通读纪律案例

## 问题1：影山优佳 —— 关联素材只读概括没读全文

**表现**：写影山优佳V2时，主素材（14岁裁判证2735字）读完了全文，但4条同事件关联素材只读了缩略信息（LEN/score/title）没读content_ja全文。导致写出来的稿子只有分析评论（翻訳者、战术分析）没有现场画面。

**关联素材全文的关键细节**：
- 荷兰战2-2后影山给清水梨纱唱生日歌、嗓子哑了唱不出高音（素材D286, 973字）→ 最生动的现场场景之一
- 梅西进球影山跳舞唱歌的视频（素材4D18, 2421字）→ 【実績解除】是她的原话
- 低角度自拍双下巴丑照（素材8016, 1659字）→ 反差萌
- グータッチ被中泽佑二评价（素材8016, 1659字）→ 专业认可

**教训**：story类画风需要丰富场景细节时，必须通读所有已关联素材的全文，而不是只读主素材+关联素材的摘要API。

**正确做法**：
```
1. 查关键字找到所有同人物/同事件的key
2. GET /api/news/<key> 读每个关联素材的content_ja全文
3. 标记每个素材的核心画面/引语/场景
4. 再动笔
```

## 问题2：纱仓真奈 —— 同台嘉宾内容占据主线

**表现**：主素材讲纱仓在美国被关5小时的经历，但同场嘉宾柏木由纪的灵异体验段落被写进了纱仓的核心文章。柏木已有独立成篇（灵异杂志经历），纱仓这篇本应聚焦纱仓的个人故事，却让柏木的段落分散注意力。

**正确做法**：同台嘉宾/同事件≠同一人。B已独立成篇时，A稿中B的出现只能作为背景（一句话交代「那天的来宾有XX」），不能展开B的独立素材内容。
