# 素材渠道分流判断指南

不是所有日本娱乐素材都走小红书。有些素材天然更适合公众号。判断方法如下。

## 快速分流表

| 适合 xhs | 适合 gzh | 跳过 |
|---------|---------|------|
| 艺人日常/趣闻/穿搭 | 深度电影/音乐/摄影美学分析 | 纯榜单/列表无上下文 |
| 争议/八卦/恋爱 | 行业分析（娱乐产业、艺人经纪） | 品牌合作软文（>50%产品参数） |
| 偶像成长/逆袭（有画面感） | 人物深度长访（有完整叙事弧） | 纯文字访谈无现场/画面 |
| OG怀旧/亲子/反差萌 | 跨文化分析（日本娱乐现象→中国语境） | セクシー女優写真宣传 |
| 简单事件（一句话能说清） | 多人物对照/行业历史梳理 | 体育/经济/政治无关内容 |

## 关键判断指标

### 1. 内容性质：是「报道」还是「分析」？

**报道型 → xhs：** 有具体事件（何时何地何人做了什么说了什么）、有画面感、有引语
- 例：「前田敦子35岁发照片」「永尾玛利亚约会」

**分析型 → gzh：** 抽象讨论、专业领域（摄影、灯光、音乐编曲）、无具体事件时间线
- 例：「山崎贤人十年的灯光变化分析」——整篇文章讨论《黄金神威》的摄影美学、油灯象征意义、两代摄影师的灯光设计传承。没有一句话是「今天山崎做了什么」，全是分析师的文本解读。

### 2. 读者门槛

**xhs读者：** 想要「看点东西」——有趣、有画面、有情绪
**公众号读者：** 能接受「读点东西」——有深度、有分析、需要思考

### 3. 素材的自足性

xhs需要素材本身有「新闻价值」——有事件、有变化、有冲突。
gzh可以借一个素材做文章——用素材作为引子，展开讨论一个更大的话题。

## 7/16实战案例：山崎贤人《黄金神威》灯光分析

**素材印象**：山崎贤人（日本艺人）× 十年对比（有时间的弧线）× 《黄金神威》（大IP）

**看似xhs，实则纯分析**：
- 正文70%在讨论油灯的使用、摄影师的灯光设计哲学、两代摄影师的传承关系
- 只有10%提到山崎本人的变化，且没有任何采访引语或事件节点
- 是一篇电影学学术文章，不是娱乐报道

**正确分流**：gzh。改写后以「从王子到猎人」的叙事弧串联，保留灯光分析核心，去掉过于学术的摄影术语，加入山崎本人的作品时间线作为背景。

**分流检查清单**：
- ☐ 素材中是否有具体事件（日期、地点、人物发言）？
- ☐ 改写后是否能提取出3个以上有画面感/信息量的引语或细节？
- ☐ 去掉分析性语言后，是否还有足够的叙事素材支撑一篇文章？
- 如果三个都是「否」→ 考虑走gzh或跳过
