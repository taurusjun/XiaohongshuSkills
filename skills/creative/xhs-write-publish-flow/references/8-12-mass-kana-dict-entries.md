## 两遍流程（8/12 实测有效）

1. **第一遍：全局 dict 替换**（python 脚本，key 按长度降序 `sorted(REPL.items(), key=lambda kv: -len(kv[0]))`，逐 key str.replace）
2. **第二遍：逐篇定向修复** — 用第二个 python 脚本按文件列 `(old, new)` 对，处理第一遍的残留：
   - 双重书名号 `《《X》》` → `《X》`
   - 括号注音重复 `元伊（元伊）` → `元伊`
   - 残余假名单词（如「トシ→敏」「ガチアドバイス→认真建议」「しょげこ→小夏」「さっちゃん→小咲」）
3. **逐篇假名重计**：`python3 -c "c=open(f).read(); print(sum(1 for ch in c if '\u3040'<=ch<='\u309f' or '\u30a0'<=ch<='\u30ff'))"`
4. **重跑 renwei**（假名清理会引入新命中，见 SKILL.md 8/12 四坑）

## 关键教训

- 替换值一律**不带《》**（原文自带书名号时避免《《X》》双重），书名号在写 draft 时就放进中文替换词或统一后处理。
- **裸后缀不进全局 dict**：ちゃん/くん/さん 逐名映射（さっちゃん→小咲，不是全局 ちゃん→酱）。
- 假名归零后 renwei 仍会 exit 1：SASUKE 12 人名单顿号分列用中文间隔号·（U+00B7）一次通过；「A的话、B的爱、C的感情」三连顿号拆开。kana清理 → renwei 必须成对重跑。
