## 新坑1：dict替换制造「X（X）」重复括号（8/23再现8/12坑，变体）

draft里同时存在「引号内中文词」+「括号内同一中文词」时（如 `"隔离舞挑战"（隔离舞挑战）`、`"男性视角"（男性视角）`），kana dict 把原文假名词替换成中文后，两处都变成中文 → 重复括号。

**8/23变体根因：** 写draft时自己在引号里写了中文译名，又在括号里写了同一中文词的注释。8/12的版本是括号注音被替换（ウォニ→元伊），这次是「自写注释」被替换。

**修法：**
1. 写draft时引号内用了中文译名，括号注释就不要再写同一个词（用罗马字或不写）
2. dict替换后 grep 括号自查：
```bash
grep -n '（' /tmp/xhs_draft_*.md   # 通读括号内是否有与引号内重复的同词
```

## 新坑2：组合名翻译别猜（原因は自分にある。案例）

「原因は自分にある。」是STARTO系男团正式名。8/23 S2山崎天稿里先被译成「原因为组合」（语义断裂，读起来完全不通），review通读时揪出改为「"原因在自己"组合」。

**规则：** 日文组合名直译后必须通读确认语义通顺。带标点/助词的名字（如「原因は自分にある。」）不能只做机械转换——先按字面译（原因在自己），再放进上下文读一遍。8/22-8/23连续两批都在STARTO系新团名上踩翻译坑。
