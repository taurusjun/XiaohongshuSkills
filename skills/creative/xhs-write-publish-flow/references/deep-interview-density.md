# 深度人物采访素材的内容密度问题

## 场景

素材是深度人物采访（深訪），content_ja 包含大量过往采访的追溯引用、历史资料复述、以及排版/图片标记。

## 问题

深访原文的「有效信息密度」与「字数」不成比例。4728字的深访原文可能包含：

- 1500字：本期的核心采访内容（引语+场景）
- 2000字：过往采访的追溯引用（《音乐与人》2007年、《CD Journal》2007年等）
- 800字：图片描述（【画像】...）
- 400字：关联文章列表、排版符号（◆◆◆ 分隔线）、作者署名

## 判断方法

### 1. 去掉明显噪音再算

```python
import re
# 去掉图片标记、分隔符、相关文章链接
cleaned = re.sub(r'【[^】]*】', '', cja)      # 图片标记
cleaned = re.sub(r'【関連記事】', '', cleaned)  # 相关文章
cleaned = re.sub(r'◆◆◆', '', cleaned)         # 分隔符
cleaned = re.sub(r'https?://\S+', '', cleaned) # 链接
cleaned = re.sub(r'\s+', '', cleaned)          # 空格换行
```

### 2. 识别追溯引用

深访文章的结构通常是：「本期采访内容（最新）」+「过去采访追溯（引文）」。追溯引用虽然字数多，但每一段都是曾经发表过的采访节选。

追溯引用的识别信号：
- 引用来源标注如「《音乐与人》2007年1月号」「《CD Journal》2007年9月号」
- 不属于本次采访的时态（「当時の彼女は…」「后来她回忆说…」）

### 3. 例外判定

去掉追溯引用和噪音后，核心本期内容与正文的比较：
- 正文充分覆盖了本期采访的核心引语和场景 → 密度问题是由原文结构导致的，不是写稿者信息增量不足
- 正文遗漏了本期采访的关键引语 → 需补充

## 案例（6/25松浦亚弥40岁深访）

| 指标 | 数据 |
|------|------|
| content_ja | 4,728 chars |
| 去噪后 | 4,604 chars（噪音占比仅2.6%，不是噪音问题） |
| 追溯引用占比 | ~2,000 chars（采访原文中大量粘贴旧采访引文） |
| 正文xhs | 1,061 |
| 原始密度 | 22.4% |
| 判定 | 深访原文结构中追溯引用占近一半，但去掉追溯引用后只剩核心~2,000 chars → 正文1,061/核心2,000=53% > 30%，实际信息增量充分 |

## 操作建议

对于深访类素材：
1. 先做标准去噪（图片标记、相关文章、分隔符）
2. 如果密度仍 < 25%，定位追溯引用段落并估算其字数占比
3. 如果追溯引用占原文 > 30%，用（正文xhs / 核心本期内容）代替密度公式
4. 核心本期内容 ≈ 总字数 - 追溯引用 - 噪音
