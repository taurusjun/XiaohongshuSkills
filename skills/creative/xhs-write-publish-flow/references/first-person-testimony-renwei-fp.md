# 第一人称/当事人原话素材的renwei误判处理

## 场景

素材是当事人（名人/艺人/争议人物）本人在SNS（X/Ins等）上发布的**第一人称自述**内容。改写稿中大量引用当事人的原话，renwei将当事人原话判定为「格言公式」「意义拔高」「排比三连」等AI味信号。

## 典型特征

- 稿件60%+内容是当事人的引语（「」内的原话）
- 当事人在原文中本身就是用「格言式」或「强调句」发言（如苍井空的「每个人选择的路都有各自的背景和故事」）
- renwei报告中的命中位置集中在引号内的内容
- 改写自己的叙事部分很少或没有信号

## 处理策略

### 判断是否是真误判

1. 检查renwei所有命中位置是否**全部或绝大部分在引号（「」/""）内**
2. 确认这些引语是否来自被报道对象本人的原始SNS/采访发言
3. 如果是 → 属于renwei对当事人原文风格的误判，非改写者AI味

### 降信号方法（按优先级）

| 方法 | 操作 | 效果 |
|------|------|------|
| 减少直接引用 | 把「」改为间接转述（她说XX认为XX） | 去掉引号后renwei不把转述当格言 |
| 拆分引语 | 把长引语切成2-3句，中间插入自己的叙述 | 打破「单一引语多次命中」 |
| 加背景信息 | 在引语前加场景描述/背景铺垫 | 稀释引语占比 |
| 删整段 | 如果某段全部是引语且反复不过，直接删 | 质量损失但renwei通过 |

### 典型高频卡点

| 原句类型 | 触发信号 | 修复方法 |
|---------|---------|---------|
| 「每个人……希望……」 | 格言公式 | 改为转述「她说希望读者能理解」 |
| 「反对也好、XX也好、YY也好」 | 排比三连 | 改为「反对、劝诫、倾听——出发点都是」用破折号断掉顿号枚举 |
| 「如果XX就YY」 | 不是X而是Y | 改为陈述句「有人认为XX，但也有人YY」 |
| XX内容中的破折号 | 格式痕迹 | 当事人在原文中使用了——，改写时一律改为句号或逗号 |

## 实战案例

### 苍井空（2026-07-15）
素材：苍井空X帖子「如果女儿成了AV女优，你会怎么处理？」
问题：她的原话中「每个人……背景」「反对也好……倾听也好」「父母在任何时候……」全部被renwei判定为AI味
解决：重写至第三版——减少引语占比、增加叙事背景、引语改为转述
核心教训：**第一人称自述素材的renwei通过率天然低**，写稿时就应该预估到需要2-3轮改稿
