# 标题深度挖掘（6/8 session）

## 问题模式

用户说"标题不够吸引人"后，第一反应是在原标题周围微调（换同义词、调语序、改标点）——这不够。需要退回素材本身。

## 案例：小坂菜绪 "气难6"

**初始标题（被否）：** "小坂菜绪想退出难相处6名单"
→ 陈述事实，无矛盾感

**第一轮修正：** "被说难相处的成员：这个标签让我们越来越远"
→ 有洞察但太抽象，对路人吸引力不够

**用户指出：** 把"美貌"放进标题，让路人也好奇"到底多美才能让人不敢靠近"

**最终标题：** "太美被说难相处，后辈连话都不敢说"
→ xhs_len=16 ✅

**关键洞察：**
标题的核心矛盾或原因（"太美"）比结果（"被贴标签"）更吸引人。因为"太美→被说难相处"是一个反直觉的因果链，而"被贴难相处标签"只是陈述。

## 正确做法当用户说"标题不够吸引人"

1. 退回素材全文，找未被使用的细节
2. 问自己：去掉成员名字后，标题还剩什么让路人想点？
3. 找到素材中反直觉的因果链（"因为A，所以B"）
4. 把原因（A）放进标题，而不是只写结果（B）
5. 用具体感（"太美"）代替抽象感（"标签的困局"）
6. 好标题公式：**原因/钩子 + 结果/反转**
