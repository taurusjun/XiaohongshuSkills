# TV/综艺完整脚本素材 -> 密度偏低处理

## 问题：素材content_ja为完整TV节目脚本

某些素材抓取到的是整段电视/综艺节目文字记录（全文脚本、访谈逐字稿、广播完整对话等），
content_ja 可能长达 2000-4000 字，远超素材实际信息量。

典型案例：佐久间大介金枪鱼（2026-06-28），
content_ja=3192字（完整「サクサクヒムヒム」节目流程），
但核心事件只是一个「尝了金枪鱼说好吃」的简单TV片段。

## 密度计算方法修正

对此类素材，密度计算基准应为：去除TV节目流程/串场/重复介绍后的核心信息字数。

### 操作步骤

1. 读完整 content_ja
2. 判断是否为TV脚本/综艺完整记录（含节目流程介绍、出演者列表、Tver推广等填充内容）
3. 如果是，将 content_ja 按 `##` 标题分割，只保留有核心信息的部分作为密度计算基准
4. 手动提取关键句，将提取后的 `dedup_ja` 传给 xhs_word_count.py 算字数

```python
# 示例：TV脚本素材 -> 只取不含填充内容的句子
import re
ja = content_ja
# 去除 "【関連記事】" 后的推广
ja = ja.split('## 【関連記事】')[0]
# 去除节目介绍前缀/出演者列表(标题在前半段，一般前20-30%)
lines = ja.split('。')
# 取有引语的句子（有人说话的内容）
quoted_lines = [s for s in lines if '「' in s or '「' in s or '【' in s]
dedup = list(dict.fromkeys(quoted_lines))
```

## 阈值

- 正常素材：密度 ≥ 30%
- TV脚本类素材（经过去填充处理后）：密度目标 ≥ 30% 或 正文xhs字数 ≥ 600字

## 综艺大素材（5000+字）的扩充策略

当素材是乃木坂工事中/日向坂等冠番组的完整节目记录（6000+字），且主素材key的content_ja覆盖了整期节目多个独立模仿秀/环节时：

### 典型场景
- content_ja=6000+字，包含节目流程、出演者名单、多个独立模仿/游戏环节
- 正文最初只写了其中一个环节（如"田村真佑强要可爱"），密度约20%
- 原文还有大量未被使用的其他成员的模仿/趣事

### 扩充策略
不要添加原文没有的信息。直接从原文中挖掘**其他成员的平行环节**：

| 原文中可提取的内容 | 用法 |
|-------------------|------|
| 其他成员的模仿表演（五百城连拍、小川恐怖表情等） | 正文扩充为"还有哪些高光模仿"段落 |
| 后辈的坦白（"顺便写了一条前辈的…"） | 充实"后辈眼中的前辈"情感点 |
| 主持人的反应和串联 | 增加现场氛围感 |

### 操作流程
1. 通读全文后，先判断正文覆盖了原文的哪些部分（通常是1-2个环节）
2. 扫原文剩余部分，标记其他可独立成段的素材
3. 每段用一个##小标题隔开，正文扩充至800-900字
4. 注意：不要超过信息总量——如果原文的"其他模仿"也很简短（只是标题列表），不能硬编细节

### 7/23验证案例
- 中西阿尔诺素材（乃木坂工事延长中第14回，6036字）
- 初始正文只写了田村真佑追击中西这一段（416字，20.3%）
- 扩充路径：加「五百城连拍」「小川恐怖表情」「后辈坦白」三个段落 → 828字，40.4%
- review得分从7.1→8.1

### 注意
- 综艺大素材通常格式=story lf=1，正文必须≥2个##小标题
- 扩充后段落数对应小标题数，每段独立成篇不混同
