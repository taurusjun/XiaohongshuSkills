# 7/1 超长单素材密度处理案例：金村美玖（8770字）

## 场景

金村美玖（日向坂46）的 SPA! 杂志深度采访，单条DB记录 content_ja = 8,770字。

## 挑战

- 单素材原文去重后：**8,534字**
- 首次正文：1,353字 → **密度15.9%** ❌
- 需要的正文量：~2,560字才能达到30%

## 解决方法（3轮扩展）

### 第1轮：基础人物story

写了常规的人物story结构（爆发点→后辈关系→从小到大的成长→私下样子→收尾），正文1,353字。

### 第2轮：挖掘采访后半段内容

重读采访全文后半部分，发现被忽略的素材：
- 「停滞だけはしたくない」原话引用
- 学打鼓的动机（生日演唱会主动表演乐器）
- 对「被叫做妈妈」的自我认知
- 和后辈的相处细节（试探式邀请、不想给压力）
- ちいかわ/ポムポムプリン入坑的完整叙事

从采访中挖掘了约400字的额外细节。

### 第3轮：补充被叫做妈妈的场景

补写了关于「妈妈」称呼的来源、后辈视角和她的自我认知的延展段落。

最终正文：2,793字 → **密度32.7%** ✅

## 规律

1. **超长采访（8000+字）单素材写人物深度story，不可避免需要较大正文量**。核心信息密度低（口语句子、重复表述多），但人物细节丰富，值得写深度

2. **扩展的素材来源必须是采访原文**，不能凭空生成。重读采访全文后半段，找到被第一次略过的段落

3. **扩展的优先级**：
   - Level 1：采访中独特/有趣的引语（金村关于「停滞」的说法、关于被依赖的不适应）
   - Level 2：场景细节（雨中打鼓、サンリオ初体验、被叫妈妈的反应）
   - Level 3：跨段落串联（金村的「妈妈」角色→后辈回应→她自己怎么看待这个角色）

4. **超长采访(8000+)的密度估算**：单条采访类素材的有效信息密度通常只有榜单/分析类素材的60-70%。同等字数下，采访素材更难到达30%门槛——因为采访原文包含大量问答转换、重复确认、寒暄段落，去重后实际信息密度更低

5. **判断是否值得扩：** 如果素材本身是高品质深度采访（单行采访、有独特引语、有人物弧光），值得在正文写2000-3000字。如果素材是流水线问答（无特色、公式化问题），建议直接按短news处理
