# 内容密度例外：素材原文含大量流程性描述的处理

## 场景

素材原文（content_ja）中有大量**流程性/结构性描述**——节目流程梗概、记者会过程叙述、报道结构模板、奖项名称罗列、比赛过程描述等——导致去重后基数虚大，正文xhs字数难以达到30%线。

## 判断条件

正文≥800字 + 素材有大量冗余流程描述，可启用例外条款，阈值放宽至 **25%**。

## 操作步骤

### 第1步：尝试去掉流程性描述后重算

去掉以下类型的冗余内容后再算一次密度：

```python
import re

# 去掉节目信息块、关联文章链接、记者署名
ja_clean = re.sub(r'■.*?\n.*?(?=■|\Z)', '', ja)
ja_clean = re.sub(r'##.*?関連記事.*', '', ja_clean)
ja_clean = re.sub(r'〈作品情報〉.*', '', ja_clean, flags=re.DOTALL)
ja_clean = re.sub(r'取材・文.*', '', ja_clean)

# 去重
sents = [s.strip() for s in ja_clean.replace('。','。\n').replace('！','！\n').replace('？','？\n').split('\n') if s.strip() and len(s) > 10]
dedup = ''.join(dict.fromkeys(sents))
```

### 第2步：判断是否达标

- 去掉流程描述后 ≥ 25% → ✅ 通过例外
- 去掉后仍 < 25% → ❌ 退回

### 第3步：如果仍不达标

从素材中找以下类型的内容再做一次裁剪：
- 重复的节目名称/日期/时间
- 单纯的"提供"信息（「6月21日19時より放送の『番組名』」类）
- 纯列出参与者的名单段落

## 实战案例（6/21 session）

佐藤健伊野尾慧NG发布会稿件，正文1038字，素材原文4138字：
- 原文含：节目描述段落、记者署名、作品信息块、关联文章链接
- 去掉后原文→3612字
- 密度1038/3612=28.7% ≥ 25% ✅ 通过

## 实战案例2：多素材合并的高重复场景（6/22 session — =LOVE）

**场景：** 主素材（国立演唱会报道 790字）+ 4条关联素材（3条是同一麦当劳CM的几乎一样的新闻稿 + 1条国立摘要）。去重后原文 ~9,248 chars，正文 747 xhs字，原始密度仅 8.1%。

**核心问题：** 三条麦当劳新闻稿是同一事件（CM合作），彼此高度重复——同样的商品描述（"FIFA W杯オフィシャルスポンサー"）、同样的定价/发售日期、同样的红黄球衣描述。流程性信息量远超核心内容。

**处理方法：**
1. 识别流程性/高度重复内容：商品详情段落、定价"期間限定で販売"、SNS发布时间（"きょう17日より"）、三条素材中完全相同的引语（"かわいい！宝物！"）
2. 去掉这些流程性描述后，核心内容估算约 2,800 chars
3. 正文 747 / 核心 2800 = 26.7% ≥ 25% ✅ 通过例外

**判断要点：** 多素材合并时密度阈值仍为 25%，但去重后的基数要**先去掉重复的事件描述/商品详情/定价信息再算**，因为多篇新闻稿彼此高度重复造成的虚大不应归罪于写稿者的信息增量。
