# 预告解禁/卡司公布型多素材合并 → 密度偏低处理

## 场景

同一作品/事件的多个媒体同时发出预告解禁报道（如7/17的道枝骏佑「M.I.S.S.I.O.N.」3媒体同时报）。各媒体覆盖相同的事实：配信日、剧情简介、卡司名单、特报映像描述、视觉海报，但在措辞和细节侧重上略有差异。

合并原文（3-4条素材的 content_ja 累加去重）可能达到 **5000-7000+ xhs字**，而一篇合理的正文在1000-1200字已经覆盖了核心剧情、卡司亮点、看点。

**2026-07-18 实战数据（道枝骏佑M.I.S.S.I.O.N.统合稿）：**

| 指标 | 数值 |
|------|------|
| 合并素材数 | 4条（#4269 1597字 + #4268 2549字 + #4265 2574字 + #4264 666字） |
| 总原文 | 7,390 chars |
| 去重后 | 5,969 xhs字 |
| 正文 | 1,103 xhs字 |
| 合密度 | **18.5%** |
| 主素材密度 | 1,103/2,574 = 42.9% |

## 问题

这种场景下，合并密度是一个**无效指标**——原文基数被多条重复性的预告报道人为放大，正文不可能也不应该等比例放大到30%密度。

## 判断方法

| 维度 | 信号 | 示例（M.I.S.S.I.O.N.） |
|------|------|------------------------|
| ✅ 原文是预告解禁型 | 同一天多家媒体发同一作品信息，内容90%重叠 | 3家媒体同时发M.I.S.S.I.O.N.解禁 |
| ✅ 正文使用多素材独特信息 | 主素材没写的卡司背景，从另一条素材补充 | #4262写了深田龙生ACEes背景，#4265写了高嶋政宏简历 |
| ✅ related_keys 有实质意义 | 关联素材的独有内容确实被用了 | #4269(深田参演) + #4268(新卡司解禁) + #4264(深田单独报道) |
| ✅ 正文信息完整 | 剧情核、卡司亮点、看点、播出信息全覆盖 | 剧情核心+3大卡司亮点+深田看点+播出信息 |
| ❌ 正文信息不足 | 只用了一条素材的信息，其他key凑数 | 不适用（本条） |

## 处理流程

1. 判断原文类型：是否是同一天多家媒体的**预告解禁报道**
2. 如果是，不依赖合并密度，改用以下两个判断标准：
   - **主素材密度**：正文xhs字 / 最长单条素材content_ja的xhs字 ≥ 30% → 通过
   - **信息增量人工判断**：正文是否用到了至少2条不同素材的独有信息
3. 报告时标注：「预告解禁型多素材合并，主素材密度X%，合并密度Y%（基准参考值）」

## 与现存例外条款的关系

| 例外类型 | 覆盖场景 | 适用吗？ |
|---------|---------|---------|
| TV脚本密度处理 | content_ja是完整TV节目流程 | ❌ 不适用——预告解禁不是TV脚本 |
| 多素材合并密度 | 同一事件多角度报道合并 | ⚠️ 部分适用——但预告解禁的"多角度"其实是同一角度不同措辞 |
| 多艺人综合报道豁免 | content_ja包含大量不相关艺人内容 | ❌ 不适用——所有内容都相关 |
| **本例外（新）** | **同一事件多家媒体同日发预告解禁** | **✅ 适用** |
