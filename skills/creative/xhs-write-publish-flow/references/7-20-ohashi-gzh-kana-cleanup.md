# 公众号稿日文假名清理案例：大桥和也电影稿（7/20）

## 背景

大桥和也首部主演电影《改变人生的段子》稿（gzh方向），原文大量使用日文假名，**总计43个**，全部来自专有名词。

## 日文假名分布（清理前）

| 来源 | 假名 | 数量 |
|------|------|------|
| 人名 せいや（霜降明星成员） | せ×7、い×7、や×7 | 21 |
| 电影名 君がトクベツ | が×2、ト×2、ク×2、ベ×2、ツ×2 | 10 |
| 角色名 こもり | こ、も、り | 3 |
| 演员名 桜田ひより | ひ、よ、り | 3 |
| 组合名 まえだまえだ | ま×2、え×2、だ×2 | 6 |

## 清理策略（按优先级）

### 1. 叙述内容中日文人名 → 用「他/她」代称替换
原文：「这个设定，来自于せいや自己的真实经历」
改后：「这个设定，来自于他的真实经历」

### 2. 引语中必须保留的人名 → 改为罗马字（不计入假名计数）
原文：正文第一次提及「这就是霜降明星成员せいや」
改后：保留一次但改为「这就是霜降明星成员搞笑艺人SEIYA」
→ SEIYA是英文字母，不计入日文假名

### 3. 演员名 → 中文译名
原文：桜田ひより
改后：樱田日阳（意译"樱田阳光"）

### 4. 角色名 → 中文描述
原文：こもり
改后：美术部的角色

### 5. 日文电影名 → 中文直译
原文：君がトクベツ
改后：你是特别的

### 6. 日文组合名 → 中文描述
原文：まえだまえだ
改后：前田前田（已无假名，纯中文字符）

### 7. 日文赛马名 → 中文意译（来自同批武元唯衣稿）
原文：ゼンダンハヤブサ（8个片假名）
改后：闪电隼

## 关键原则

- **英文字母不计入假名计数**：SEIYA vs せいや → SEIYA可行，せいや不可行
- **日文→中文译名时，优先找公开中文译名**；没有时采用直译/意译
- **引用中出现的人名**：第一次后全部「他/她」代称
- 最终：43 → 0，renwei通过
