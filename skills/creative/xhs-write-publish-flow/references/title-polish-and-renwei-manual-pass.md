# 标题打磨 + 正文手工去味（renwei 脚本盲区补丁）

10/21 板野友美「肉盒直置き」稿（`9bd19ab6…`，story lf=1 / cj 3853 / export 1601字）实测。
用户连续 4 轮打回标题、再让正文过 renwei，踩出的可复用规则。

## 一、日语词陷阱：`育ち` ≠ 「出身」

- 素材原题是「なぜ“育ちの問題”に見えたのか」。`育ち` = 成长环境 / 家教 / 教养。
- 中文「出身」指阶级或家庭背景（科班出身、农民出身），**不能形容礼仪**，而且「补上了出身」这种搭配中文不成句。
- 正确替换：`育ち` → **教养 / 家教 / 家教问题**（按上下文选；标题里用「没教养」最有冲击）。
- 通用动作：标题或正文出现读着别扭的抽象词（出身 / 成长 / 立场 / 分寸），回 `content_ja` grep 原词再定译，不要凭日文汉字直译。同类已记录：けやき坂→榉坂、ひなた坂→日向坂（禁自造「平假名坂46」）。
- 正文其余位置要跟着改，否则标题用「没教养」、正文还在「出身」= 两套词。10/21 一次改 4 处：小标题下提问句、`翻译成出身两个字的`、`被追问的不是…成长`、`出身这个词`。

## 二、标题：争论必须写出来，但不能用镜像模板

四个版本的实际打回原因（同一篇，全部 ≤20 字）：

| 版本 | 标题 | 打回原因 |
|---|---|---|
| v1 | 观众替她补上了出身 | ①「出身」是日语直译 ②不够吸引人 |
| v2 | 板野友美被说没教养，替她说话的人更多 | 用户：**"题目上没有体现争论"** |
| v3 | 有人骂板野友美没教养，有人说我家也这样 | 用户：**"ai味道太浓了，不是。。。也是。。。"** |
| v4 ✓ | 板野友美被骂没教养，网友：我家也这样 | 过 |

可机械执行的规则：

1. **"体现争论" ≠ 复述有争议。** 「替她说话的人更多」是结论，读者没有插话空间；必须把**两边能被站队的原话**摆出来（骂的人说「教养露出来了」/ 留言者说「我家平时也连盒上桌」）。
2. **禁用镜像/对仗模板**做这件事。「有人…有人…」「一边…一边…」「不是X，也是Y」「A就B，C就D」都算，用户一眼认出是 AI。
3. **首选「X：原话」引语式**。`板野友美被骂没教养，网友：我家也这样` = 单句 + 冒号引原话，小红书原生写法，无模板感，争论还在。
4. 名人名必须在标题里（无名的疑问句版点击会掉，可作备选不作主选）。
5. 想冲一点可用「骂X的人，家里也这么吃」这类（17字），但会替留言者站队，与正文「不责怪留言的人」冲突——正文中立时不要选。

## 三、renwei 脚本 0 命中的时候，人工必须补这四类

`renwei-pre-commit.py` 10/21 对 1605 字正文报 **0 处 / 0 类 通过**，但人工过一遍抓到 8 处。脚本是正则，只认识列出的形态：

| 盲区 | 实测例句 | 改法 |
|---|---|---|
| 「不是X，是Y」**不带「而是」的变体** | 变的不是食物本身，是它的样子。／这不是礼仪问题，是包装… | 改成单边陈述：`变的只是摆法。`／`礼仪本身没问题，是…` |
| 「真正…的，是…」重复 | 真正解开这个结的，是…偏差。／真正让人不舒服的，是… | 换口语：`心理学里有个说法叫…，能解开这个结。`／拆成两句 |
| 镜像对仗（非顿号排比） | 期待被满足就生出好感，被打破就容易变成反感。 | 收成一句：`期待落空的时候，好感很容易翻成反感。` |
| 签到式过渡 | 还有一层容易被忽略。 | 直接删，下一句照常成立 |

另外两个高频处：

- **万字展望结尾整段删**。10/21 删掉约 110 字（「下次对某个画面生出不适时，先想想…」+「不是A也不是B」），全文改以 `是一扇不拍处境的窗` 收尾，结论落在具体机制上，不替读者总结。
- **`##` 小标题也要过一遍**。`## 摆盘研究：变的是样子，不是那块肉` 是正文同款对仗；改成 `## 摆盘研究：换个摆法，味道评价会变`，否则和改过的正文用两套说法。脚本按正文行扫，小标题行最容易被漏。

## 四、要留住的"手迹"（别一起清掉）

- `同一个人，同一个动作，用了两把尺子。` — 全篇核心观察，对仗但不空，删了文章散。
- `那为什么一盒肉能扯到「没教养」？` — 自问自答只出现一次，承上是转折不是表演。
- `这不是要责怪留言的人。谁的脑子都会这样。` — 「不是」是让步不是模板；后半句是人的口气，删了变腔调。

判断口径还是「聚集」：单处信号不动，同类 ≥2 或跨类 ≥3 才动手。
