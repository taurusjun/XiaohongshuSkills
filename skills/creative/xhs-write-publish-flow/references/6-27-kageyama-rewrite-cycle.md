# 影山优佳重写循环（6/27）

## 背景

6条关联素材（主素材14岁裁判证1904字、战术板2006字、梅西进球1684字、荷兰战824字、熬夜看球1118字、声カス生日歌673字），去重后8114 xhs_len字。

用户拆成3篇写的要求正确——单篇不可能覆盖所有素材达到30%密度。

## 关键教训

### 1. 多素材必须拆篇

当一组关联素材去重后超过3000 xhs_len字，必须拆成多篇，各自绑定2-3条素材。密度计算时基准 = 本稿用到的所有素材content_ja去重后xhs_len。

### 2. 开场决定成败

**错误开场**：从童年/背景讲起（「5岁开始在老家踢球」）
**正确开场**：从现场画面切入（「6月14日荷兰战2-2平局，她握拳跳起来」）
翻译版要比改写版写得好：翻译版用「开幕中的FIFA世界杯2026，首战突尼斯，她在看台如痴如醉地盯着比赛」开场，直接带读者进入现场。

### 3. 字数算法的时效性

`xhs_word_count.py`可能中途被修改。旧规则（CJK×1+半角×0.5）→新规则（全部×1，换行符不计）。**每次新入库前必须重新用脚本算当前内容字数**，不能依赖历史数据。

### 4. 关联素材的content字段

`content`字段是中文翻译版，`content_ja`是日文原版。密度计算用content_ja。但翻译版的写作质量可作为改写质量的参考基准——如果翻译版写得更好，借鉴它的结构。

### 5. 密度计算完整流程

收集本稿用到的所有素材key → 各取content_ja → 按。！？拆句 → set去重 → xhs_content_len算基准 → 正文xhs_content_len / 基准 ≥ 30%
