# 7/6 实战案例：大岛麻衣"约会钱包"争议三素材合并

## 背景

元AKB48大岛麻衣（38岁）在NewsPicks的Instagram上说"约会时女生不该掏钱包"，引发网络激烈争议。

## 涉及素材（3篇）

| key | 视角 | content_ja长度 | 
|-----|------|---------------|
| 628c16caf3842619a71ef213ba6eb894749ccef2 | 主发言+网友批判 | 956字 |
| 1fc45c8ca0f346a5937fa9e42964b6a683c5e797 | 补充她哥的教导+中嶋优月/杉本彩不同观点 | 1088字 |
| 52eb84d12b558b8812487bf50dda3a4e16ce3cbb | 搞笑艺人真栄田贤X上回应（指名制调侃） | 563字 |

## 处理方式

### 初始错误判断
我一开始判定为"争议话题跳过"——错误。用户纠正：争议本身就是流量，关键在于写法。

### 最终写法
**中立观察者视角**，不站队。结构：
1. **起因**：大岛发言+哥哥的教导
2. **反应**：网友激烈两派观点+大岛人物背景
3. **延伸**：中嶋优月（23岁）"请我是看不起我吗"、杉本彩（57岁）"AA绝对不行"、真栄田贤（50岁）列名单谁付谁AA

### 入库结果
- 主key: 628c16ca → rewritten_title + rewritten_content（726字）
- related_keys: 互设3条key双向关联
- 密度: 26.4% → 走多观点综合报道豁免（原文为多人物/多年龄段讨论一个社会现象）

## 学习要点

1. **不要因为"观点不对"就跳过素材** — 小红书不是教科书，争议型内容天然有讨论价值
2. **判断标准不是价值观对错，而是"读者有没有讨论欲望"**
3. **同事件多素材合并**：3篇不同角度→1篇短稿，比各自写3篇信息更集中
4. **写法铁律**：只呈现、不站队。数据+引语让读者自己判断
