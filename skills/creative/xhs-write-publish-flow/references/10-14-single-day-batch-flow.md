## 本批坑（新增）

1. **heredoc 里内联 `\n\n` 拼接多段中文长串会触发 `unterminated string literal`** —— 改写文件内容时用三引号 `"""..."""` 变量承接，再循环 append，不要在一行里用 `\n\n` 拼两段长文本。
2. **`normalize-dunhao.py` 会把动词/短语列表也换成间隔号 ·，读起来生硬**（「画绘本、拍电影·经营线上沙龙」「深深受伤·痛苦」）。跑完脚本必须抽查 2–3 处，把「动作/短语并列」的 · 手工回改成「，还」「和」。人名/团体名/作品名列表的 · 保留。
3. **precheck 的 `ja` 分母必须用 `xhs_content_len`（不是 raw len）**；raw 偏大 1–3%，密度被低估。plan.json 由脚本从 list dump 直接生成，不手填。
4. **人名/团体名中文化一次到位（本批实测）**：ミミ萩原→咪咪萩原、曽野舜太→曾野舜太、澁谷→涩谷、愛川ゆず季→爱川柚季、窪塚俊介→洼冢俊介、ふぉ～ゆ～→Fuu~yu~（罗马字）、＝LOVE 保留、Aぇ!group→Ae!group、倉木華→仓木华、西野亮廣→西野亮广。
   日文新字体：発→发（超長発球→超长发球）、髪→发（金髪→金发）、変→变（激変→激变）、愛→爱（愛MUST BE→爱 MUST BE）、広→广（広島→广岛）。本批靠写稿时人工中文化，precheck 的 SHINTAI_FAIL 类未含「変/愛」，全靠人工。
5. **`publish_xhs=1` 是整数 1/0**，直接查 DB 时禁止写 `'published'`。已发布 = `publish_xhs=1 AND COALESCE(publish_time,'')!=''`。
6. **正文 >900 字的 post 稿在排期前要压到 880–910**：本批 5b31b54c 初稿 912 → 改到 885（删「粗算下来」等冗余词），重跑 renwei（exit 2）→ 重入库（score_dims 保留）。
