# 中文评审标准

评分维度（各 2 分，满分 10 分）：

## 1. 爆发点（2分）
- 开头是否有吸引人继续读的钩子
- 2分：第一段就抓住读者，有冲突/悬念/名场面
- 1分：开头平淡但后续有亮点
- 0分：开头无关紧要或信息堆砌

## 2. 情绪价值（2分）
- 读者读完后的情绪反应（感动/愤怒/惊讶/共鸣）
- 2分：有明显情绪波动，有记忆点
- 1分：有情绪但不强烈
- 0分：纯信息陈述，看完没感觉

## 3. 信息增量（2分）
- 比日文原文多了什么新角度/深度
- 2分：有原文没有的解读、细节补充、多素材合并后的新视角
- 1分：基本覆盖原文要点但无延展
- 0分：比原文还少

## 4. 内容深度（2分）
- 是否有背景铺垫、人物关系、事件因果
- 2分：有完整背景交代，路人也能看懂
- 1分：有基础背景但不够
- 0分：默认读者什么都知道

## 5. 标题质量（2分）
- 标题是否有钩子、数字、矛盾
- 用 `xhs_title_len()` 检查标题字数：**一律 ≤20（news/story 同限）**，超过直接判 0 分
- 2分：有钩子+有信息+不超字数
- 1分：有钩子但超字数，或有信息但没钩子
- 0分：平淡/超字数/标题党

## 内容密度（否决项，不通过则直接退修）
- 正文长度必须 ≥ 原始素材去重后的 **30%**
**计算方式：**
1. 收集：主素材content_ja + 每个related_keys素材的content_ja
2. 去重：把所有文本按 `。！？` 拆成句子，用 set() 去重后重新拼回
3. 计算：`xhs_len(正文) / xhs_len(去重后原文) * 100`
   - 正文和基准都用 `xhs_len()`（脚本 `scripts/xhs_word_count.py` 的 `xhs_len`函数：全角字符×1，半角字符×0.5，向上取整）
   - ❌ 不要用 `len()` 算基准 —— 半角英数被按×1算，密度偏低
   - ❌ 不要用 `re.findall(r'[\u4e00-\u9fff]')` 筛纯汉字 —— 漏日文假名
4. 低于30% → 判定"信息增量严重不足"，不进入评分流程，退回补充素材或合并关联条目
- 示例：柏木由纪主素材1626字 + 关联素材0 → 原文1626字。如果关联素材里有一段和主素材完全一样，去掉重复段后原文可能只剩1400字。正文605字 / 1400字 = 43.2%而非37.2%。

## 格式检查（否决项，不通过则直接退修）
- 正文不以标题行开头
- 用 ## 小标题分段
- 无 **加粗**
- 原话引用有三要素（谁+情境+说了什么）
- 日式表述已本地化（婚活→相亲 等）
