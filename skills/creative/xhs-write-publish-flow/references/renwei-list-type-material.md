# 名单型/预告型素材的renwei处理（6/30 谷口爱季案例）

## 问题模式

预告型素材（节目出演名单、舞蹈对决阵容、演唱会曲目等）天然包含大量列举——这是内容本身的属性，不是写作风格的AI味。

但renwei脚本不区分别列是内容属性还是AI句式套路。排比三连（顿号分列）和列举名单会被判定为「句式套路·排比三连」。

## 6/30 谷口爱季舞蹈对决改稿实录

**第一版**（exit 1拒绝）：
- 排比三连×2：`LDH选了13人，由其旗下GENERATIONS、THE RAMPAGE、BALLISTIK BOYZ等团` + `乃木坂、樱坂、日向坂三个团的舞踊担当`
- 破折号×4
- 填充语×1：「尤其值得注意的是」
- 跨类≥3 → **exit 1**

**修复策略（第2版）：**
1. 列举名单改写散句：`GENERATIONS、THE RAMPAGE、BALLISTIK BOYZ` → `来自GENERATIONS、THE RAMPAGE、BALLISTIK BOYZ等多个团体`（减少顿号密度）
2. 破折号替换：`「DREAM ダンス」的企划——七大事务所` → `七大事务所`
3. 填充语删除：删「尤其值得注意的是」
→ exit 1仍然拒绝（排比三连剩2处+破折号剩2处→跨类≥3）

**修复策略（第3版）：**
4. 进一步改为每个团单独成短句：`来自GENERATIONS、THE RAMPAGE、BALLISTIK BOYZ等多个团体` → 改写成几句自然话
5. 剩余破折号也替换掉
→ exit 2通过（排比三连1处+破折号1处=跨类2=非聚集）

## 名单型素材的renwei通过模板

```markdown
LDH派了13人，来自多个团体。

坂道联合队9人。领衔的是樱坂46的谷口爱季。乃木坂46派出了岩本莲加和一之濑美空，日向坂46的金村美玖也在阵中。

STARTO方面有Kis-My-Ft2的千贺健永，Travis Japan的宫近海斗和中村海人等。
```

关键技巧：每个团单独成句 → `{团名}派出了{人名}` 而不是 `{团名}的{人1}、{人2}、{人3}`
