# Session 6/5: Writing structure, concision rules & workflow discipline

## Key learnings from this session

### Structure rules (hard requirements, user-enforced)
- All long-form articles MUST use ##小标题分段 (3-6 segments)
- NO 一/二/三 numbering as headings — each heading must be a specific scene anchor
- NO **加粗 in content body — emphasis must come from content, not formatting
- First draft must already be structured — structure is NOT an iteration item

### Word count modes (user-defined)
- **短news**: ~900 chars, single scene single angle
- **长文story**: UNLIMITED words, use all material, 40%+ density vs original

### Original quote rule
- Never truncate: "小学时候她就跟爸妈说想当偶像" is incomplete — must include "因为喜欢AKB48" context
- Keep 3 elements: WHO + CONTEXT + WHAT THEY SAID

### 中泽莉佳子 iteration log (8 rounds)
- Round 1: 900字无结构 → 7.2
- Round 2: 分小标题 → 7.5
- Round 3: 去**→ 7.5 (content thinned)
- Round 4: 加浓两场景(逃试/电话) → 7.7
- Round 5: 扩到1700字+六段结构 → 7.5 (too thin)
- Round 6: 去一/二/三+补前因 → ~6.0 (reviewer swing)
- Round 7: 电话场景加"声控灯灭"→ 7.7
- Round 8: 大胃王前置+"一桥大"展开 → 8/9/7 A-

### Workflow discipline (user-enforced repeatedly)
Write → IMMEDIATE入库 (no asking) → review → [if <8] revise → review again → [if ≥8] tell user
NO intermediate questions. NO TG preview before review passes.
