## 3. 踩过的两个「看着像汉字其实是假名」

1. **`おいしいのつくりかた` → 误写《美味作り方》**：`り` 是平假名，落在
   U+3040–U+309F 区间，**假名计数器会命中**（10/1 实测 345622d0 kana=1 就是这一个字）。
   凡曲名/作品名里夹单字假名（作り方、恋する、食べる…），必须整词意译。
2. **`カフェオーレ` 这类片假名组合名**：与 9/19 的 `日本コロムビア`、
   9/21 的 `Aぇ!group` 同一机制——片假名外来语在公司名/组合名里极易原样落笔。

## 4. 复查命令

```bash
cd /tmp/drafts<MMDD>
python3 - <<'PYEOF'
import glob
for p in sorted(glob.glob('xhs_draft_*.md')):
    t = open(p).read()
    k = [c for c in t if '\u3040' <= c <= '\u309f' or '\u30a0' <= c <= '\u30ff']
    if k:
        print(p, 'kana:', ''.join(k))
PYEOF
```
打印出具体是哪些字，比只给计数有用得多——能直接定位到人名/曲名，一步替换。
