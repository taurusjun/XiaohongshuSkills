# 7/6 实战案例：百合川美织 — 高敏感身份人物逆转型写法

## 背景

百合川美织（百合川みおり）—— 现役性感女优，同时也是前地下偶像、写真偶像。她的经历：被霸凌到不上学→15岁Jr.偶像出道→大学当院长秘书被舔脚→2023年转性感女优→爸爸说"加油"→梦想开珠宝品牌。

这条素材的敏感点：职业身份（性感女优）。写不好会显得猎奇或judge。

## 写法原则

### ❌ 错误写法
- "她曾是清纯偶像，如今沦为……"（judge）
- "从被霸凌的女孩到脱下衣服的她"（猎奇）
- 在正文中讨论"你怎么看待这个职业"（价值观输出）

### ✅ 正确写法
- **当普通人物逆转型写**：霸凌→出道→被骚扰→转行→家人支持→新梦想，和任何逆转型人物同样的叙事弧线
- **不评价职业选择**：\"转性感女优\"作为事实陈述出现，不需要加修饰语
- **原话优先**：她自己在采访中说\"反正老老实实上班也会被性骚扰，那不如索性脱了\"——这句比任何旁白都更有力
- **结尾落在具体行动上**（开珠宝品牌），不做人生总结

## 结构

```
标题：具体冲突事件（被霸凌+被舔脚）+ 她的态度弧线
├── 被霸凌到不上学（拒绝归因于"命运"）
├── 院长秘书被舔脚（她自己的转折点引语）
├── 爸爸说"加油"（温暖的意外反转）
└── 100岁也要继续（具体梦想+未来行动）
```

## 关键引语（原文自带，不要替换或润色）

1. "老师亲自来我家，当着我的面说的这句话"（霸凌不被学校承认）
2. "反正老老实实上班也会被性骚扰，那不如索性脱了"（转行原因）
3. 爸爸看到体育报纸后说"加油！"（家庭支持的反转）
4. "那我做到100岁"（轻快收尾）

## 注意事项

- 性感女优的身份在标题中要用暗示而非直白描述——标题写"被上司舔脚"比"从清纯偶像到性感女优"更克制
- 正文中提及职业时用中性表述「在2023年以性感女优身份出道」即可，不要加"最终""选择""走向"这类暗示路径必然性的词
- renwei审读特别关注点：格言公式（"X是Y的Z"句式）在这类素材里容易聚集，注意替换为平实转述
- 超S级逆转型——这是已验证阅读天花板最高的类型，遇到了直接写，不要犹豫
