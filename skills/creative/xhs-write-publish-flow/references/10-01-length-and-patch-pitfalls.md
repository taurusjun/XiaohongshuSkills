# 10/1 跨日积压批实作 —— 长度校准、patch 陷阱、机械门禁脚本

本文件记录 10/1 会话（跨 9/28~10/1 四日积压）里消耗工具调用最多的三类问题。
批次台账（写了哪些、合并了哪些）见 `10-01-crossday-backlog-batch-flow.md`。

---

## 1. 中文落笔长度比自估短 40~60%（本会话最大浪费源）

**实测数字。** 一段自认为「大约 400 字」的中文段落，`scripts/xhs_word_count.py` 只算
240~260 字。50 篇稿里 30 篇以上首轮不达标，其中 6 篇 story 反复补了 4~6 轮才同时过
「≥800 字」和「密度 ≥30%」两道门禁。最坏的一例卡在 **body=798/800**，连补两次才过。

**规则：**

- story 首轮目标 = `ja_len × 0.32`，再上浮 15% 落笔。不要按「看起来够长」判断。
- ≤1500 字素材 → 850 字起写;3000 字 → 950;4000~5000 字 → 1350~1500；
  5000+ 字 → 1700+;8000+ 字 → 2500~3200。（与 SKILL.md 的 ×0.31~0.33 表一致）
- 字数只能用脚本判断。`python3 scripts/xhs_word_count.py "<正文>"` 或直接跑
  `scripts/batch_precheck.py`。

**补字一次到位，不要小句补丁。** 判定不达标后，**一次补 ≥150 字**（一个完整段落，
或两句带新信息的句子）。反面教材：一次补 5~50 字的替换要跑一轮 precheck 才知道够不够，
同一篇补 4 次仍差 2 字。一轮到位的成本是 1 次补丁，卡在 798 的成本是 3~4 次补丁
加 3~4 次 precheck。

**补什么：** 优先挖素材里**还没用过的**细节 —— 未引用的引语、配角姓名、数字、场地、
时间线。不要为凑字数把已写过的信息点写第二遍（撞 8/17 / 8/31 的跨小节重复坑）。

## 2. plan.json 缺项 → draft 被静默 SKIP，「FAIL 0」是假的

`scripts/batch_precheck.py` 对 `plan` 里没有的 key 只打印
`SKIP <k12> (plan 里没有这个 key，先补 fmt/lf/ja 再判)`，**不计入 FAIL**，
末尾照样输出「N 篇检查完毕，FAIL 0 篇」。

10/1 实测：写好 7 篇新 story 后只跑了旧 plan，读到「12 篇检查完毕，FAIL 1 篇」以为通过，
实际新写的几篇一篇都没进检查；补齐 plan 条目后同一批立刻暴露 7 篇 FAIL
（字数 / 顿号 / 密度）。

**规则：每新增一批 draft，先把它们的 `key12 -> {fmt, lf, ja}` 写进 plan.json 再跑 precheck；
跑完确认「检查完毕」的 N 等于 draft 目录里的 `.md` 文件数，不等就是有 SKIP。**
生 plan 条目时直接从当日 `l1_raw_<date>.json` 批量填，不要手抄。

## 3. 结构性 patch 的锚点：不要用 draft 首行（标题行）

给 draft 插新 `##` 小节时，若把锚点选成文件首行（那其实是 `## 标题`），
标题会被顶掉、正文多出一个重复的 `##`，precheck 的标题栏会显示成小节名。

10/1 实测：`4d13f39d45c5` 上以 `## 隔着亚克力板被求婚…`（标题行）为锚点插入新小节，
结果首行变成小节标题，正文出现两个同名 `##`，靠 `grep -n '^##'` 才发现。

**规则：插入 `##` 小节时锚点选文件中部的既有小节标题；结构性 patch 之后跑一次
`grep -n '^##' <file>` 核对首行为标题、无重名小节，再进 precheck。**

## 4. 顿号行归零：用脚本，不要手改

`batch_precheck.py` 把「行内 `、` ≥ 2」判为 FAIL（同一条也触发 renwei 的「排比三连」）。
SKILL.md 规定枚举一律换中文间隔号 U+00B7。

**直接跑 `scripts/normalize-dunhao.py <dir>`**（就地：行内第 2 个及以后的 `、` → `·`）。
本会话两批共 50 篇，用它一次清完，比逐行手改可靠。

## 5. 10/1 新增的 renwei 假阳性与假名来源

`renwei-pre-commit.py` 的「格言公式」正则
`[^。，！？]{2,20}(的|之)(路|语言|镜子|货币|篇章|缩影|写照)` 会命中中文常用短语，
本次一共踩到 5 处，全部是 `的` + `路`：

| 原文 | 修法 |
|------|------|
| 走的是能动起来的**路**线 | 拍摄安排偏活动型 |
| 她走**的**路在日本女偶像里… | 她这条线… |
| 毕业之后**的路**线基本就是… | 毕业之后的方向基本就是… |
| 跟以往**的路**子差得比较远 | 跟以往差得比较远 |
| 一度以为自己的**路**也到头了（标题行） | 一度以为演艺生涯也到头了 |

**规律：`路线 / 路子 / 她的路 / 之后的路` 一律改「方向 / 线」；标题行也会被扫到，改完补看标题。**

假名来源（本次新增，均靠终检揪出）：

| 来源 | 示例 | 替换 |
|------|------|------|
| 活动名里的单字假名 | 「**た**行」（五十音分段） | 「ta行」 |
| 艺人艺名全假名 | **あの**（歌手） | 歌手ano |
| 旧写法遗留 | てつや（YouTuber 本名） | TETSUYA |

同一条经验复用：**写稿前先把候选名单里的活动名 / 组合名 / 人名跑一次假名 grep**，
不要等终检。

## 6. 密度豁免要用、但要写明口径

三类的处理方式（本次都用到，均在 review 里写进口径）：

| 素材类型 | 口径 |
|---------|------|
| 配信片单 / 作品一览（ja 里 70%+ 是目录） | 豁免；写编辑正文，注明「作品一览占原文约 N 字」 |
| 榜单 / 排行榜（映画动员、下载榜） | 不豁免，按 `ja×0.31` 写足；5 维度受公告类天花板约束（7.8~8.3） |
| 多艺人活动 report（目标人物是 8 人班底之一） | 豁免，改写 800 字左右 + 讲清目标人物在这台子上的位置 |

豁免只免密度，**不免字数门禁与 5 维度评分**。
