# 深访类型素材的内容密度边界案例

## 案例：松浦亚弥40岁深访（2026-06-25）

**素材：** 松浦亚弥40岁生日深访第2回（4728字）
**正文：** 1061 xhs字（5个小标题分段）
**原始密度：** 22.4%
**去噪后密度：** 23.0%
**结论：** ❌ 未达标（去噪后<25%）

**为什么密度低：**
- 原文4728字中，约50%是早期采访追溯引用（《音乐与人》2007年、《CD Journal》2007年）
- 约10%是排版符号（◆◆◆、【图片N】）和相关文章链接
- 正文本身内容扎实——5个小标题覆盖16岁挫折→18岁自我认知→渡良瀬橋转折→隐退后接孩子，有完整故事弧线

**判断：** 这是结构性问题（深访的原文基数中有大量追忆性材料），不是写稿信息增量不足。不能因为「原因合理」就自己决定pass密度检查。

**处理流程（写在此处供参考，不是建议跳过规则）：**
1. 如实标记密度值
2. 汇报时说明原因
3. 让用户决定

**类似特征的识别信号：**
- content_ja ≥ 4000字
- 大量引用刊物名（「《XXXX》XXXX年X月号」）
- 内容类型为「深访」「インタビュー」「对话」等
- 正文有完整故事弧线但密度持续<25%
