## =LOVE 国立+巨蛋 续集式合并（场景C实战）

**场景：** 同一事件链的多阶段素材，跨周合并为一篇

**背景：**
- 6/17 三条旧素材：麦当劳CM红黄球衣 + 改词版情歌 + 「为国立蓄力中」
- 6/22 两条新素材：国立穿日本队球衣返场 + 巨蛋发表
- 旧素材均未写稿，新素材当天入库

**路线选择：** 模式B（开头覆盖）——旧稿正文不动，在前面加新开篇hook

**操作：**
1. 用最新事件key（f32ca87）作为主素材
2. 读三条旧素材的content_ja，提取「蓄力中」的引语
3. 写开篇hook：「三周前麦当劳→三周后国立」
4. 正文保留原有「安可穿球衣→巨蛋发表→三个月倒计时」三段
5. related_keys关联5条素材（旧3+新2）

**结果：** 811字，xhs_len=747，三周弧线完整。review 8.2分。

**关键教训：**
- 续集式合并的钩子在「蓄力→兑现」的对比弧线，不是信息堆叠
- 合并后密度检查需要算所有相关素材的去重原文；流程性描述（商品详情/定价/SNS时间）可以剔除再算密度
- 密度不达标时，先确认是否有大量重复描述或流程性内容

## 川荣李奈 字数压缩（1036→868）

**场景：** 用户看完写稿结果后要求"字数控制在900左右"

**操作：**
1. 识别冗余段落最严重处：三家剧的罗列（《隔壁的护士助理》《废柴经理》《假妈妈》）
2. 定位砍刀位置：去掉逐个列举的剧名，换成对比性叙事（总选16位vs晨间剧三代目）
3. 替换内容来自素材自身：前田敦子/大岛优子的对比数据本身就存在于素材中
4. 收紧结尾：去掉总结腔「她的演员简历比任何标签都有说服力」，换成粉丝评论

**结果：** 1036→868 xhs字。review评分8.0→8.1。密度30.9%。

**关键教训：**
- 用户对字数有要求时，不等用户催着改，主动压缩到目标值
- 压缩的优先顺序：剧作罗列/流程描述 → 替换为叙事性对比 → 收紧结尾
- 砍掉的数量从素材自身找替代素材，不要凭空补
