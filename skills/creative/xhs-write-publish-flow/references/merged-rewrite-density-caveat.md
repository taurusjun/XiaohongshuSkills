# 旧稿合并的内容密度警示（6/12 session 验证）

## 现象

当旧素材已存在 `rewritten_content`（如能条爱未旧稿已733字、preselected=1），因新素材（同人物、同事件的新报道）产生而需要合并更新时，**正文字数/原文总量占比天然偏低**。

6/12 session案例：
- 原文总长 = 旧key content_ja 1233字 + 3条related素材 878+868+1744 = 4723字
- 正文字数 = 998字（合并后的新rewritten_content）
- 占比 = **21%**（远低于30%最低密度线）

原因是：旧稿的 rewritten_content 本身就是对原始 content_ja 的改写版本，与新素材的 content_ja 相加后，原文总量膨胀了，但正文只做了结构性补充而非完全重写。

## 对review的影响

Reviewer 会依据规则7（内容密度）扣分：
- 21% → 判定为「严重不足」→ 情绪价值和爆发点各扣1-2分
- 即使正文逻辑完整、引语准确、场景覆盖率高

## 正确应对

### 方案A（推荐）：扩充正文至30%以上

在合并旧稿时，主动将正文扩充到占原文总量的30%以上：

1. 从旧key的content_ja中挖掘旧稿未使用的场景细节
2. 从新素材的content_ja中补充更多引语和场景描写
3. 增加「传承叙事」段落（如三田宽子自己从偶像嫁入梨园的映射）
4. 补充能条爱未退圈的心理变化（给人物留棱角）

对于能条爱未案例（原文4723字），需要将正文扩充至约**1400-1600字**才能达到30%。

### 方案B：接受低密度，按短news标准

判断是否值得花时间扩充：
- 如果素材本身是「单事件追加补充」而非「全新角度」→ 保持短news字数（~900字），按短news的7分线通过即可
- 如果素材追加提供了全新信息增量（如节目新片段、新引语）→ 走方案A

### 判断标准

能用方案B（按短news通过）的场景：
- 新素材与旧稿是同一次事件的不同报道角度（如同一节目的不同媒体稿）
- 新素材没有增加结构性的新场景/新人物/新冲突
- 旧稿已经较为完整

需要用方案A的场景：
- 新素材存在旧稿未覆盖的**结构性的新内容**（新人物引语、新场景、新冲突）
- 旧稿本身较短（<600字），扩充空间大
- 用户明确说「补充新素材细节」而不是「合并后按短news处理」

## 实操检查清单

合并前先问：
1. 旧稿字数是多少？（如果<600字 → 大概率需要方案A）
2. 新素材有没有旧稿没覆盖的引语/场景？（有 → 方案A）
3. 原文总量是多少？（如果>3000字 → 用~900字正文怎么都过不了30%线，必须判断是方案A还是B）
4. 如果选方案B，review给6-7分是正常的，不要追8+
5. 如果选方案A，扩充目标=（原文总量×0.3 - 当前正文字数）
