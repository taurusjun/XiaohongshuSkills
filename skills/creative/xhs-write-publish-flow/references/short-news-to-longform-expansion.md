# 短news→长文story扩展决策指南

## 信号：什么情况下短news可以扩成长文

6/10 session 野吕佳代案例验证：原文是单事件短news（一篇杂志采访总结，1184字content_ja），用户说"试试写成长文"后，从859字短news扩展到1135字长文，review从7.8→9.0。

### 判断标准

短news扩成长文**不是所有素材都可以**，必须满足以下条件：

1. **有完整故事弧线** — 不是"今天发生了X"的单点事件，而是有"起点→困境→转机→高潮→收束"的叙事骨架
2. **有核心矛盾/冲突** — 不是信息汇总，而是"外部压力 vs 内心欲望"的对抗（野吕例：虚报年龄被发现 vs 被秋元康拯救的荒诞）
3. **有具体数字/场景** — 至少2-3个可触摸的画面（握手会2个人、有吉骂"笨蛋"）
4. **有第一人称引语** — 采访中的原话，不是转述（"走过红毯时我想那两个人现在在哪里"）
5. **素材信息密度够** — content_ja至少800字以上，且包含行业冷知识或细节

### 不适合扩展的信号

- 纯粉丝向短讯（晒照/行程/写真预告/数据播报）→ 保持preselected=1，不改写
- 原文只有1-2条引语且无场景描写 → 天花板就是短news
- 事件还未落地（如久保小新6/15才揭晓）→ 等揭晓后再写
- 素材来源是单一官方report → 信息量固定，扩展只是注水

### 扩展方法（野吕佳代案例验证有效）

1. **加上家业/成长线** — 原文只说"22岁报名AKB"，但另一条素材里有"爸爸是美容师→上美容学校→退学追梦"，加入了开头的"弯路"段落
2. **加金句** — 原文interview里"看到一个人全心全意努力的样子，会让我心里感到热"放在被有吉骂醒之后，自然收束
3. **保留爆点回环** — 结尾"她走过的不是戛纳的红毯，是17年前那排空荡荡的握手会队伍"从短news保留下来，是全文最高分段落
4. **不虚构** — 所有扩写内容来自content_ja中已有的细节，不从想象中补戏
