# 6/17 Session 写稿案例记录

## 本session核心教训

### 1. 入库后必须跑review再汇报

写了10篇稿件（大野智纹身、M!LK公众号、柏木由纪、二宫和也、DOMOTO、野吕佳代、AKB大TOP 4条、影山优佳）后直接汇报"全部完成"，被用户问"都没有经过review？"

**正确流程：** 批量写稿完成后→统一跑一轮review（密度+三维评分）→ 列出每篇得分 → 改不合格的 → 再汇报。

### 2. content字段张冠李戴（野吕佳代→柏木由纪）

素材 e2675402 的 content（AI摘要）提到柏木由纪，但 content_ja 里没有任何"柏木"出现的痕迹——实际原文写的是野吕佳代和沢口靖子。

修复：重读 content_ja 后改写成野吕佳代版本。

**根因：** 没执行"写前先读content_ja确认关键人物"的规则。
**修复：** 阶段1a 设为写前强制步骤。

### 3. 纯粉丝向短讯被错误改写了

市川美织（6ca3748）——发烫伤照问粉丝怎么不留疤 → 纯粉丝向短讯，不应该写 rewritten。
川崎希（0540104）——晒次女照片 → 同上。

修复：清空 rewritten_content，publish_mode 恢复 normal，仅 preselected=1。

**根因：** 没有做内容路由判断（阶段1b）就直接动笔。
**修复：** 阶段1b 强制在 content_ja 之后判断路由，纯短讯直接跳到阶段5。

### 4. 柏木由纪基调问题（三改才到位）

v1：太严肃，每段结尾排比金句（"一个说紧张，一个说风格""从零到有人举应援扇，只需要三天"）。
v2：用户说"像在看自家小孩第一次上台表演"——但结尾还是有点总结倾向。
v3：标题从"600人到场的新团vs初演7人：柏木由纪的17年"（作者视角总结）改为"柏木由纪看新人团：才出道就有600人应援？"（正文里人物原话语气）。

**基调判断方法：** 问"一个普通路人点进来想看什么"，不是"我想表达什么"。

### 5. 内容密度边界案例（影山优佳）

4篇素材去重后原文4106字，正文852字/xhs 816 → 密度19.9%（不达标）。
3篇核心素材去重后3186字，正文852字 → 密度26.7%（仍不达标）。

原因是素材原文有大量重复性比赛流程描述（时间/比分/出场阵容），去重后基数仍然很大。

**结论：** 新增25%例外条款——当正文≥800字且素材原文结构松散时，阈值降至25%。
