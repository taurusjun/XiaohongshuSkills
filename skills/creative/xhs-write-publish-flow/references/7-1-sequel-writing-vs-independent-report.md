# 7/1 花田蓝衣续集写作教训：当素材已有前篇时

## 场景

花田蓝衣剃发事件已有前篇（已入库 `rewritten_content`），用户要求写"第二篇"（900字xhs版）。

## 关键教训

### 1. 续集 ≠ 独立报道

当素材是同一事件的后续时：
- **不能**从头写事件经过（开场画面、视频场景、谁做了什么）
- **必须**假设读者已经读过前篇，开头一两句交代背景即可，快速切入新角度
- 花田蓝衣修正前：第一段写了花田发视频、剃光头的场景描写（前篇已有）→ 被批评"浪费字数"
- 花田蓝衣修正后：开头半句"回应来回弹了好几天"交代续集背景，直接切入铃木收

### 2. 续集的角度选择

| 前篇写过的 | 续集应该写 |
|-----------|-----------|
| 事件经过（谁、何时、发生什么） | 新进展/新观点/新角度 |
| 当事人原话引语 | 其他人的反应、第三方分析 |
| 现场画面描写 | 规律总结、行业观察 |
| 基础信息（人物背景） | 深度分析、传播机制 |

花田蓝衣案例：前篇的叙事线是"花田发视频→运营否认→罗生门"；续集的角度是"铃木收的传播学观察→沉默吃亏→速度差矛盾"。

### 3. 续集写作自检表

写稿前先查：这篇素材同人物的前篇是什么角度？如果已有，当前素材的新角度是什么？

- [ ] 开头是否在重复前篇已覆盖的基本事件经过？如果是，砍到一句话以内
- [ ] 本文的核心信息点，有哪个是前篇完全没有提到的？
- [ ] 读者读完前篇后再读这篇，能获得的新信息是什么？
- [ ] 如果去掉开头的背景交代段本文还能独立成立吗？（续集应该能，只是开头快一点）

### 4. 翻译版 content 字段的 review 规则

翻译版（DB的`content`字段）和改写版（`rewritten_content`）的review标准不同：

| 维度 | 翻译版 | 改写版 |
|------|--------|--------|
| 信息增量 | 不适用（纯翻译） | 必须有新增角度 |
| 其他4维度 | 正常评分 | 正常评分 |
| 整体分 | 满分8分（不评标题） | 满分10分 |
| 判定 | 作为资料参考 | 作为可发布稿件 |

翻译版如果信息增量=0，5维度总分上限为8（不计标题），通常5-6分=合格的资料参考，但不可作为改写稿发布。
