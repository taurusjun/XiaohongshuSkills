# 歌单/榜单/曲目列表类素材的密度处理

## 场景

content_ja 是以下类型时，**绝大多数内容是不可用的列表噪声**：

1. **Billboard/Spotify 合作歌单**：如「Top Japan Hits by Women」——几十到上百首歌曲列表，每首只有歌名+艺人名，目标人物的新曲只出现在列表中的一行
2. **音乐节目曲目表**：如「Mステ出演曲目」「FNS曲順」——全是歌名+歌手
3. **榜单排名**：Oricon周榜、Billboard JAPAN Hot 100等
4. **商品列表**：杂志推荐商品清单、时尚品牌穿搭表

## 核心问题

这类 content_ja 的 **xhs_len 可能很大**（因列表超长），但**有效叙述内容极少**（目标人物通常只有1-2句描述）。用常规密度计算必然极低（<10%），但这不代表改写质量差。

**真实案例（7/12 session）：** 中森明菜新曲「ごめんと、すきと、」
- content_ja: 2345 chars（其中约2300chars是90首歌曲的列表+歌名）
- 有效描述中森明菜的句子：**仅1句**（「这是中森明菜约10年来的首张新单曲」）
- 改写正文: 716 xhs字（合并了A7生放送素材，增加了明菜30年Mステ背景）
- 直算密度: 27.5%
- 实际信息增量: 充足（合并两条素材+提供背景）

## 处理流程

### 第1步：识别

读 content_ja 的前20-30%行。如果出现以下模式，判定为列表类素材：
- 连续20行以上是「歌名+艺人名」格式
- 多数行只有「曲名」或「曲名 - 艺术家」结构
- target人物只在开头/结尾出现1-2次

### 第2步：密度豁免逻辑

**不要**用整篇 content_ja 的字数计算密度。

**正确判断信息增量的方法：**

| 条件 | 判定 |
|------|------|
| 目标人物在原文中有可用的引语/自述（≥1句） | ✅ 可写，豁免密度 |
| 目标人物在原文中只有一句介绍（「新曲发布」类） | ⚠️ 需要合并其他关联素材 |
| 目标人物完全不出现在正文中，只有标题提到 | ❌ 不可写（标题党素材） |
| 有其他同人物/同事件关联素材可合并 | ✅ 合并后写，豁免密度 |

### 第3步：密度报告格式

不要报「密度=XX%」——这个数字对列表类素材没有意义。改为报告：

```
原文类型: 歌单/榜单/曲目列表（90%+为列表噪声）
有效内容: [目标人物在原文中出现的句子数或字数]
信息增量判断: [充足/不足]
说明: [合并了哪些关联素材，补充了什么背景]
```

## 与多艺人综合豁免的区别

| 维度 | 多艺人综合报道 | 歌单/榜单列表 |
|------|-------------|-------------|
| 原文结构 | 每段讲一个艺人，有引语和背景 | 纯列表，只有歌名+艺人名 |
| 噪声比例 | 50-70%（其他艺人内容） | 90-99%（列表噪声） |
| 可用内容 | 目标人物有自己的段落（有引语） | 目标人物可能只有一句话 |
| 密度策略 | 提取目标人物段落做分母 | 放弃密度计算，改判断信息增量 |
