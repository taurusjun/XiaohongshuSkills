# 成员名罗马音规则 + 团体名标准写法

## 罗马音规则

- 成员名优先使用本人或事务所官方公布的罗马音拼写
- 如果官方罗马音不明确，使用日本标准罗马音（Heplburn式）
- 长音不写（例：こうき → Koki，不是 Kōki）
- 姓在前名在后（例：Nakagawa Runka，不是 Runka Nakagawa）
- 团体名连写不空格（例：Sakurazaka46，不是 Sakura Zaka 46）
- 混成词首字母大写（例：Cho Tokimeki Sendenbu）
